Observation

GET /api/status, /api/stream, /api/events, /api/export, /api/system. GET /video.mjpg returns the newest captured JPEGs.

Writes

All POST routes require X-Station-Token from GET /api/session and the same origin.

POST /api/command: {"text":"forward","duration_s":0.5}. POST /api/lease: {"enabled":true}; refresh each second. POST /api/release cancels laptop motion and pauses a mission.

POST /api/mission: {"name":"Search","points":[{"latitude":17.385,"longitude":78.4867,"altitude_m":10,"hold_s":0}]}. Each point must be in the configured flight envelope.

POST /api/mission/action: {"action":"start"}; also pause/resume/cancel. Live execution requires both config flags, the operator lease and all flight gates.

GET /api/missions and POST /api/missions/save persist plans.

POST /api/copilot/plan: {"text":"search 20 by 20 meters at 10 meters"}. Supported local intents include search, perimeter, orbit, measured movement and return home.

POST /api/ai/policy: {"policy":"advisory"} or pause_on_person.

POST /api/simulation: person_visible, gps_loss, video_loss, battery_percent, time_scale. Demo mode only.

POST /api/search-grid: latitude/longitude/width_m/height_m/spacing_m. Returns a GeoJSON draft.

POST /api/incidents: {"note":"Observation"}. Saves a current frame and fresh aircraft location.

POST /api/recording/start and /api/recording/stop. GET /recordings/{filename} downloads a completed AVI.

Aircraft arming, takeoff and flight mode selection remain with the pilot. Guided execution streams velocity requests; it does not upload an onboard mission. See the OpenAPI schema for all input constraints.
