# Reference outputs

These are selected existing development reports and images, supplied for comparison and continuation. They are historical observations on the original laptop, not results measured on a new laptop or proof of detection accuracy. See each report's limitations and the model provenance notes in ML/README.md.

- `dashboard/`: preview and completed integration-check results.
- `pretrained_screening/`: the four-model screening report and representative frame 543 comparison. Models use different training data and class sets.
- `enhancement/`: earlier phase reports retained for project continuity.

Generate new runs in the ignored output folders; preserve source/model/settings and use a labelled evaluation set when making accuracy claims. Absolute original-workstation paths in report metadata are historical references and are not required for setup.
